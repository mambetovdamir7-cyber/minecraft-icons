О проекте

Фанатская галерея текстур Minecraft Java Edition 1.21.4.

1 059 текстур в одном месте

Все предметы игры и все блоки, у которых нет предметной иконки. Дубли и служебные кадры анимаций убраны, поэтому в каталоге нет мусора вроде clock_37.

Почему 16×16

Это родное разрешение ванильных текстур Java Edition — других в игре нет. При скачивании можно выбрать 16, 64, 128 или 256 px: увеличение идёт целыми пикселями (imageSmoothingEnabled = false), без мыла и интерполяции.

Откуда текстуры

Оригинальные PNG из ресурсов игры 1.21.4, собранные из клиентских ассетов. Ничего не перерисовывалось и не сжималось с потерей качества.

Как пользоваться

Клавиша / — поиск, ← и → — листать карточки, Esc — закрыть. Звёздочка на карточке добавляет иконку в «Избранное», оно хранится в браузере и никуда не отправляется.

Команда для игры

В карточке есть кнопка «Копировать /give» — она кладёт в буфер /give @p minecraft:<id> 1. ID показывается рядом с названием.
